# Vorlage: Turnusprüfung

Verkürzt. Sie prüft nicht alles noch einmal, sondern beantwortet eine andere Frage: **Gilt die letzte Prüfung noch?**

Die vollständige Prüfung läuft erneut, sobald ein Auslöser eingetreten ist — nicht zum Turnustermin. Der Turnus ist eine Untergrenze, keine Hauptmaßnahme.

**Gegenstand:** ___  **Letzte vollständige Prüfung:** ___ (Produktversion ___)  **Heute:** ___  **Geprüft durch:** ___

---

## 1 Die fünf Fragen

- [ ] **Stimmt der Einsatzzweck noch wörtlich?** Wenn nein: vollständige Prüfung
- [ ] **Ist der Eigentümer noch im Haus und noch zuständig?**
- [ ] **Hat sich Modell oder Version geändert?** Aktuelle Angabe: ___
- [ ] **Wie viele Ausgaben wurden im letzten Monat geändert oder verworfen?** ___
- [ ] **Ist ein Auslöser eingetreten, der nicht gemeldet wurde?**

Frage 5 ist unangenehm und notwendig. Häufige Ja-Antworten sind ein Befund über den **Meldeweg**, nicht über die Person.

Frage 4 gehört mit dem Wert der Vorperiode verglichen. Ein Rückgang gegen Null bedeutet, dass die Aufsicht formal geworden ist, ohne dass jemand das entschieden hätte.

## 2 Auslöser

| Auslöser | Eingetreten | Bekannt geworden durch | Folge |
|---|---|---|---|
| Zweckbestimmung geändert | | | |
| Modellwechsel beim Anbieter | | | |
| neue Datenquelle oder Datenart | | | |
| erweiterter Nutzerkreis | | | |
| Aufsicht entfallen oder geschwächt | | | |
| Rechtsänderung | | | |

Die Spalte **bekannt geworden durch** ist die lehrreichste des ganzen Dokuments. Steht dort über mehrere Prüfungen hinweg nur „Zufall", fehlt kein Feld, sondern ein Verfahren.

## 3 Vorkehrungen, die laufen sollten

- [ ] **Testsatz** ist seit der letzten Prüfung gelaufen — Anzahl Durchläufe: ___
- [ ] Abweichungen im Testsatz: ___
- [ ] **Änderungsverlauf** des Anbieters wurde gelesen — zuletzt am: ___
- [ ] Die benannte Stelle für den Änderungsverlauf ist noch besetzt

Ein Testsatz, der eingerichtet ist und nicht läuft, ist keine Vorkehrung. Die Zahl der Durchläufe gehört deshalb hin, nicht ein Haken.

## 4 Nachweise

- [ ] Nachweise mit **Versionsbezug** auf die aktuell laufende Version geprüft
- [ ] Nachweise, die durch eine neue Produktversion ungültig wurden, auf „offen" zurückgesetzt
- [ ] Zustände stimmen: kein Nachweis steht auf „freigegeben" für eine Version, die nicht mehr läuft
- [ ] **Probe:** einen Nachweis angefordert, Zeit gemessen: ___

Punkt 2 ist der, der am häufigsten fehlt. Ein Register, in dem Nachweise nur vorwärts laufen können, veraltet lautlos.

## 5 Befunde der letzten Prüfung

| # | Befund | Termin war | Status heute | Neuer Termin |
|---|---|---|---|---|
| | | | | |

Ein Befund, der dreimal verschoben wurde, ist keine offene Aufgabe mehr, sondern eine Entscheidung, die niemand ausgesprochen hat. Das gehört in dieser Tabelle sichtbar gemacht und eskaliert.

## 6 Art. 4 — KI-Kompetenz

- [ ] Personenkreis, der das System bedient, ist noch derselbe
- [ ] Neue Personen sind geschult, mit Datum
- [ ] Bei Modellwechsel: geprüft, ob die Schulung noch passt

Der letzte Punkt wird übersehen. Eine Schulung, die erklärt, wie das alte Modell irrt, passt nach einem Modellwechsel nicht mehr.

## 7 Rechtsstand

- [ ] Geprüft, ob sich Anhang I oder Anhang III geändert haben
- [ ] Geprüft, ob neue Leitlinien, Durchführungsrechtsakte oder harmonisierte Normen vorliegen
- [ ] Geprüft, ob eine Frist seit der letzten Prüfung **anwendbar geworden** ist

Zur letzten Zeile die derzeit relevanten Daten: Art. 50 Transparenz seit **2.8.2026** anwendbar; Anhang III Hochrisiko ab **2.12.2027**; Anhang I ab 2.8.2028.

## Ergebnis

- [ ] **Keine Änderung.** Die letzte Prüfung gilt weiter. Nächste Turnusprüfung: ___
- [ ] **Änderung ohne Klassenwirkung.** Prüfung ergänzt, Begründung: ___
- [ ] **Vollständige Prüfung erforderlich.** Verantwortlich: ___ Termin: ___
- [ ] **Betrieb aussetzen.** Begründung: ___
